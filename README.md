# 📱 PhotoTrek Journey (Flutter & Dart)

A cross-platform mobile and web application built with **Flutter 3.44+ & Dart 3.12+** targeting:
* 🍏 **iOS / iPhone & iPad**
* 🤖 **Android (Phones & Tablets)**
* 🌐 **Web (PWA on Chromebooks / Chrome)**
* 💻 **macOS / Windows / Linux Desktop**

---

## ⚡ Features
1. **🗺️ Interactive Map & Navigation:** Explore American photography waypoints with Apple Maps & Google Maps navigation intents.
2. **📋 Bucket List Checklist:** Real-time completion progress tracking.
3. **🛰️ 2-Opt & Nearest Neighbor VRP Solver:** Calculates optimal routes with lighting window constraints.
4. **☀️ Solar Azimuth & Elevation Compass HUD:** Astronomical sun positioning for golden/blue hour planning.
5. **🚌 COPPA-Safe School Bus & Field Trip Dispatcher:** Anonymous passenger headcount, on-time dismissal bell buffers, and Zooniverse Citizen Science Micro-Grant offset tracking.

---

## 🚀 How to Run

### Run on iOS Simulator / iPhone:
```bash
flutter run -d ios
```

### Run on Android Device / Emulator:
```bash
flutter run -d android
```

### Run on Web (Chrome):
```bash
flutter run -d chrome
```

### Execute Unit Tests:
```bash
flutter test
```
